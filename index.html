Prashmit Mohapatra

I spent months building this world. I wanted to create a story that feels like stepping into an ancient, mist-covered ruin—where every shadow holds a secret and the map itself is a character.

I'm just a 7th grader who loves dark fantasy, mysteries, and stories that challenge reality. If I can build a world, so can you. This is my debut, but it won't be my last.
